## Development-only use cases

The `global-development` workspace includes **Developer shortcuts > Use cases**, visible to users with an `administrator`/`admin`, `developer`, or `designer` role. Use cases are English-only, with no language field or translation support. Each use case has a title, description, and ordered steps. Each step has a title and plain-text description, outcome, initiator, recipient, and actors fields.

Topic pages in that workspace offer a **Use case list** under **Page sections**, containing references to use-case documents. Both schema types, the section option, and navigation entry are gated by the workspace dataset and are not registered in other datasets.

This feature provides Studio authoring only; website rendering is not implemented.

Navigation visibility does not replace document permissions configured in Sanity project roles.
